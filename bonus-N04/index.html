AI社員を動かす道具マップ2026

何を・どこに置くか。この特典を読み終える30分後には、今日開く道具が1つに決まっています。

はじめに

「AI社員を作るのはいいとして、結局どのツールを使えばいいのか」

ここで止まっている時間が、いちばんもったいないです。道具を探している時間は、作業をしていない時間だからです。

そして厳しい話をひとつ。新しい道具を探しているとき、たいていは今持っている道具を使いこなせていません。役割の指示書をきちんと持たせるだけで、同じ道具でも出てくるものが変わります。道具のせいにする前に、渡し方を見直すほうが早いことがほとんどです。

その上で、それでも道具そのもので解決する部分があります。この特典はそこだけを扱います。

情報の目安は2026年8月時点のものです。AIの道具は料金も機能も変わるのが速いので、実際に課金する前に必ず公式サイトで最新を確認してください。

この特典の進め方

この特典は、上から順に読んで、最後に1つだけ空欄を埋める作りになっています。

  1. 道具の向き不向きを知る（本体）
  2. 自分の作業と道具を線でつなぐ（対応表）
  3. 置き場所を決める（フォルダの雛形）
  4. 入れる順番を決める（無料→有料）
  5. 迷ったときの決め方を持っておく

読みながらメモを取る必要はありません。最後に埋める欄が、そのままメモになります。

最初のゴール（今日やる1つ）

読み終えたら、これだけ埋めてください。

■ 最初に渡す作業：

■ その作業に使う道具：

■ 今日やること（1つだけ・30分以内で終わるもの）：

■ いつやるか（時刻を書く）：

時刻まで書いてください。「今日中に」と書くと、だいたい明日になります。

道具マップ本体（用途 × ツール × 置き場）

まず全体を1枚で見渡します。作業から逆引きできる形にしています。

用途 向いているツール 使いどころ（1行） 置き場の目安
対話しながら下書きを作る ChatGPT / Claude（チャット版） 指示書を貼って動かす、を最初に体験するならここ 無料から。ブラウザだけで始められる
制作物をまとめてファイルで作る Claude Code など、ファイルを直接操作するエージェント型ツール 「この構成で原稿を書いて、章ごとにファイルへ分けて」で、実際にファイルができ上がる 本格的に使うなら有料プランが前提。詳細は公式サイトを確認
自分の資料をもとに答えさせる NotebookLM 過去の原稿や返信を読ませて、自分の判断基準を引き出す 無料から。有料の上位プランもある
調べる・複数の情報源をまとめる Genspark など、リサーチ特化のAIツール 調べものを投げると複数の情報源をまとめて返す 無料枠がある。まずはそこから
手元のファイルを横断して書き換える Cursor たくさんのファイルを見ながら一括で編集する 無料版と有料版がある
チャットからパソコンごと動かす 自律型のAIエージェントツール（OSSで公開されているものが増えている） 目標を渡すと、段取りを組んで実行まで進める 道具自体は無料でも、動かす裏側のAI利用料は別にかかることが多い

各ツールの使いどころは、この1行だけ覚えておけば十分です。迷ったら表に戻ってきてください。

役割別「この仕事はこの道具」対応表

企画を1本回すのに実際に必要な役割を数えると、リサーチ・構成・コピー・スライド・図解・配信文・告知の投稿・教材の整形・サポート返信・数字の集計、これだけで10個あります。さらに前半用と後半用のように分かれる役割もあるので、実際にはもっと増えます。

同じ人に前半も後半もやらせると、どっちつかずになります。だから分けます。以下は、その考え方で組んだ対応表の抜粋です。自分に近い行だけ見てください。全部は要りません。

役割 やること 向いている道具
リサーチ（一次情報を集める） テーマについて複数の情報源を集める Genspark など
リサーチ（数字・事実の裏取り） 出てきた数字や固有名詞を検証する Genspark＋ChatGPT/Claude併用
構成担当 骨組み・章立てを作る ChatGPT / Claude
コピー担当（見出し） 見出し・キャッチコピーの案出し ChatGPT / Claude
コピー担当（本文の言い回し） できた本文の言葉づかいを整える ChatGPT / Claude
スライド担当（構成案） スライドの流れ・枚数を設計する ChatGPT / Claude
スライド担当（ファイル化） 構成案を実際のスライドファイルへ落とす Claude Code
図解担当 考え方を図にする Claude Code、または画像生成系ツール
配信文担当（前半・興味付け） 読み手の興味を引く導入を書く ChatGPT / Claude
配信文担当（後半・締切訴求） 締切や行動を促す文を書く ChatGPT / Claude
告知投稿担当 SNS向けの短文を作る ChatGPT / Claude
教材整形担当 文章を配布用のファイル形式へ整える Claude Code
サポート返信担当 よくある質問への一次回答案を作る ChatGPT / Claude＋NotebookLM
数字集計担当 実績・応募数などを集計する Claude Code、または表計算系ツールとの連携
LP構成担当 ページの骨組みを設計する ChatGPT / Claude
LP本文担当 構成に沿って本文を書く ChatGPT / Claude

この表は「30人ぜんぶ作れ」という意味ではありません。時間を食っていて、かつ判断がほとんど要らない役割から作ると、最初の3人がすぐ決まります。多くの場合、コピー担当・教材整形担当・配信文担当のどれかが最初の候補になります。

フォルダ構成の雛形（最小構成）

道具を増やすと、次に困るのが置き場所です。役割が増えるほど、「お客さんの像」「トーン」「禁止事項」のような共通の前提を、毎回貼って渡す手間が発生します。

最小構成はこれで足ります。

AI社員フォルダ/
├── 00_共通/
│   ├── お客さんの像.md
│   ├── トーンと禁止事項.md
│   └── 用語集.md
├── 01_リサーチ担当/
│   └── 指示書.md
├── 02_構成担当/
│   └── 指示書.md
├── 03_コピー担当/
│   └── 指示書.md
├── 04_配信文担当/
│   └── 指示書.md
└── 99_振り返り/
    └── 月次まとめ.md

00_共通 にまとめた前提を、各担当の指示書の冒頭で「これを読んでから作業して」と参照させる形にします。これで、担当が増えても貼り直す手間が増えません。

役割を1人作るたびに、次の4つを先に決めてください。埋まっていないまま作ると、必ず作り直しになります。

■ 役割の名前：
■ この担当がやること：
■ この担当がやらないこと：
■ 渡す材料（何を渡せば動けるか）：
■ 合格ライン（数えられる形で3つ）：
　1.
　2.
　3.

「やらないこと」は特に大事です。たとえばLP構成担当とLP本文担当を分けたとき、本文担当が勝手に構成を変えてしまうことがあります。対策は、後工程の担当の「やらないこと」に、前工程の領域をはっきり書いておくことです。

【やらないこと】
・構成そのものを変更すること
・ブロックの順番を入れ替えること
　→ 構成に問題がある場合は、書かずに指摘して止まること

導入する順番（無料→有料）

いきなり全部入れないでください。1つ目でつまずくと、道具のせいにして止まります。そして「AIは自分には無理だった」という結論だけが残ります。これがいちばんもったいない終わり方です。

順番はこうです。

  1. 無料で1人動かす。ChatGPTかClaudeのチャット版で、指示書を貼って役割を1つ動かしてみます。ここで「動く感覚」を掴みます。
  2. 制作物が多いなら、ファイルを直接操作するエージェント型ツールを検討する。コピーして貼り付けて保存する作業が1日に何度も発生している人は、ここで戻ってくるものが大きくなります。料金体系は各社で異なるため、公式サイトで最新のプランを確認してから決めてください。
  3. 自分の資料をもとに答えさせたくなったら、NotebookLMを無料の範囲で試す。過去の原稿や返信を読ませておくと、自分らしい言い回しが出やすくなります。
  4. 調べものが増えてきたら、リサーチ特化ツールを無料枠から使う。ただし、出てきた結果はそのまま使わず、必ず元の情報にあたってください。
  5. ファイルの横断編集が必要になったら、Cursorのようなツールを検討する。ここは第二の脳を本格的に作る段階で効いてきます。
  6. 決まった手順を毎回同じように動かしたくなったら、自律型のエージェントツールを検討する。できることが広い分、任せる範囲を先に決めておかないと事故につながります。指示書がより重要になります。

動く感覚が分かってから道具を増やすほうが、結局早く進みます。いきなり課金して、使わないまま月額だけ払い続けるのが、いちばん損なパターンです。

迷ったときの決め方

3つの質問に答えるだけで、今日開く道具が決まります。

Q1. AI社員を1人でも作って動かしたことがあるか？
　　NO  → ChatGPTまたはClaudeで、指示書を持たせて1人動かす。ここで終わり
　　YES → Q2へ

Q2. 出てきた文章をコピーして貼り付ける作業が、1日10回以上あるか？
　　YES → ファイルを直接操作するエージェント型ツールを試す
　　NO  → Q3へ

Q3. 出てくるものが「自分らしくない」と感じるか？
　　YES → 自分の資料を読ませられるツールで判断基準を引き出す
　　NO  → いまの道具のまま、渡す作業を1つ増やす

Q1でNOだった場合、道具の話はいったん忘れてください。1人も作っていない段階で道具を比べても、判断材料がありません。

新しい道具が出るたびに気になる人は、この基準だけ持っておいてください。

いま使っている道具で、具体的に困っていることがあるか。

困っていないなら、乗り換える理由はありません。困っていることが言葉にできないなら、それは道具の問題ではないことが多いです。

最初に投げるプロンプト

道具を選ぶ前に、まず自分の作業を棚卸しします。ChatGPTかClaudeに、そのままこの通り貼ってください。

あなたは業務の棚卸しを手伝うアシスタントです。
私がこれから、自分の作業リストを書き出します。
それぞれについて、次の3つを判定してください。

1. 週にどれくらい時間がかかっているか（目安でよい）
2. 判断がどれくらい要るか（★★★＝ほぼ不要／★★＝基準があれば渡せる／★＝判断が多い）
3. 上記2つから見て、最初に人に渡す（AIに任せる）候補として優先度が高いか

すべての作業を判定したあと、優先度が最も高い3つを理由つきで教えてください。
専門用語は使わず、短い文で答えてください。

【私の作業リスト】
（ここに、いつもやっている作業を箇条書きで貼る）

よくある失敗7つと直し方

  1. 一度に全部の道具を入れる → 1つの作業に1つの道具、と決めてから増やします。
  2. 新しい道具が出るたびに乗り換える → 「今の道具で具体的に困っていることがあるか」だけを基準にします。
  3. 無料のまま重い作業を続けて時間だけが減らない → 制作物が多い人は、有料化の検討タイミングを先に決めておきます。
  4. 課金してから初めて動かす経験をする → 先に無料の範囲で1人動かしてから、課金する道具を決めます。
  5. リサーチ結果をそのまま使う → 出てきた数字や固有名詞は、必ず元の情報にあたって確認します。
  6. 役割どうしの担当範囲が被って、勝手に領域を越えて動く → 「やらないこと」に前工程・後工程の境界を明記します。
  7. 道具を増やしたのに一度も呼ばない担当が増える → 月に1回、「今月1回も呼ばなかった担当」を数えます。3人以上いたら作りすぎです。

安全に使うための注意

  • 個人情報や機密にあたる情報は、そのままAIに貼らないでください。伏せ字にするか、渡す前に削ってください。
  • リサーチ担当には、必ず出典URLを出させる指示を入れてください。出典のないまとめは、便利に見えて確認する手段がありません。
  • パソコンを直接操作する自律型のツールは、任せる範囲（触ってよいフォルダ・実行してよい操作）を先に決めてから使ってください。範囲を決めずに使うと、意図しないファイル操作につながります。
  • 料金プランのあるツールは、無料枠の上限や自動更新の条件を、契約前に公式サイトで確認してください。
  • 出力をそのまま公開・送信する前に、必ず人の目で最終確認してください。AIの出力は下書きです。

つまずいたときに聞くプロンプト

道具を入れたのに動かない、成果が出ないと感じたら、これをそのまま貼ってください。

私は今、AIを使った作業でつまずいています。
以下の状況を読んで、原因が「道具の問題」なのか「渡し方（指示書）の問題」なのかを判定してください。
判定したら、次に試すべき具体的な1手を、短く1つだけ提案してください。

【今使っている道具】

【任せている作業】

【困っていること（具体的に）】

【指示書を渡しているか（Yes/No、Yesならその内容の概要）】

用語集

  • AI社員：決まった役割を持たせて、繰り返し動かすAIのこと。
  • 指示書：役割・やること・やらないこと・渡す材料・合格ラインをまとめた文書。AI社員を毎回同じ品質で動かすための土台。
  • チャット型AI：会話しながら下書きを作るタイプ。ChatGPTやClaudeのチャット版など。
  • エージェント型AI：目標を渡すと段取りを組んで実行まで進めるタイプ。
  • ファイル操作型ツール：チャットの中で完結せず、実際にファイルを作って保存してくれるタイプ。
  • リサーチ特化AI：調べものを投げると複数の情報源をまとめて返すタイプ。
  • ノートブック型AI：自分が渡した資料だけを読んで答えるタイプ。ネット全体からは拾わない。
  • 自律型AI：チャットから指示を出すと、パソコンの中で作業を自分で進めるタイプ。
  • 第二の脳：自分の判断基準・過去の成果物を、AIが参照できる形で置いておく場所のこと。
  • 切り替えコスト：道具や担当を増やすたびに発生する、「どれで何をやるか」を判断する余分な負担のこと。

出す前の品質チェック（10項目）

道具を選んで動かす前に、この10項目を確認してください。

  1. 最初に渡す作業を1つに絞ったか
  2. その作業に、判断がほとんど要らないことを確認したか
  3. 使う道具の料金プランを、公式サイトで確認したか
  4. 個人情報・機密にあたる情報を渡していないか
  5. リサーチ担当に出典を出させる指示を入れたか
  6. 「やらないこと」を指示書に書いたか
  7. 合格ラインを、数えられる形で3つ書いたか
  8. 今日やることが30分以内で終わる粒度になっているか
  9. いつやるか、時刻まで決めたか
  10. 出力をそのまま使わず、人の目で最終確認する前提になっているか

最新AI（2026年9月時点）でこの特典はどう変わるか

この特典では: 道具マップの「操作」の列に、コンピュータ操作型の AI が入りました。専用の API が無いアプリでも画面経由で動かせる前提で、道具の選び方を見直してください。

2026年9月の第1週に、主要な AI が続けて更新されました。この特典の手順は変わりませんが、次の3点を知っておくと手数が減ります（2026年9月6日時点の公開情報です。提供状況は変わるので、使う前に各社の公式サイトで確かめてください）。

  • GPT-6 Astra（OpenAI・2026年9月3日発表）: 画面の情報を読み取り、アプリを人間と同じ画面経由で動かす「コンピュータ操作」が主機能になりました。フォーム入力・表計算・資料づくりのような「手順が決まっている作業」を任せやすくなります。ただし段階的な提供の途中で、自分のアカウントにまだ出ていないことがあります。画面に映った文章をそのまま指示として読むことがあるので、AI に画面を触らせるときは「映すものを選ぶ」を守ってください。
  • Claude Fable 5.1（Anthropic・2026年9月1日発表）: 数時間から数日にわたる、複数アプリをまたぐ作業を最小限の監督で回すための最上位モデルです。この特典の作業は Sonnet／Opus で足ります。「何日もかかる仕事を丸ごと任せる」段階になってから検討してください。Claude Code の導入は特典「Claude Code 最初の30分」で扱っています。
  • AI社員: 上の2つが向いている先は同じです。「毎回同じ指示を書かなくていい担当」を1人ずつ増やす形が、個人でも現実になりました。この特典のプロンプトやシステム指示は、そのまま AI社員の「指示書」の1枚になります。つくり方は特典「AI社員1人目のつくり方」で扱っています。

モデルの差で成果は決まりません。何に使うかで決まります。この特典の手順を1周してから、新しいモデルを試してください。
