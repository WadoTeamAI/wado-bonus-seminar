セミナー復習 壁打ち Gem

セミナーで聞いた「稼ぐ順番」の話を、当日のメモから自分の言葉に言い直し、翌朝に「まず何をやるか」を1つに絞れるようになります。

はじめに

セミナーを聞いているときは「わかった」と思っても、翌日にはその8割を忘れています。これは記憶力の問題ではなく、聞いた話を自分の言葉に変換していないからです。

この特典は、セミナーで話した「稼ぐ順番」の3段階の考え方を、あなた専用の壁打ち相手（Gem）に整理してもらうための道具です。当日のメモを貼るだけで、内容の要約はしません。かわりに「あなたはどう理解しましたか」「今のあなたはどこにいますか」と聞き返し、あなた自身の言葉と、あなたのケースに落とし込むところまで一緒に進めます。

聞いた話を寝かせずに、翌朝のうちに自分のものにする。この特典の役目はそれだけです。

この特典の進め方

  1. Gemini で新しい Gem を作り、下の「Gem のシステム指示 全文」をそのまま貼り付けます
  2. セミナー当日にとったメモ、印象に残った一言、聞きながら考えたことをGemに貼ります
  3. Gemからの質問に、思ったままの言葉で答えます。うまくまとまっていなくて構いません
  4. 「今の自分はどの段階にいるか」を一緒に整理します
  5. 最後に、翌朝いちばん最初にやることを1つだけ選びます

Geminiが使えない場合は、後半の「汎用プロンプト版」をChatGPTやClaudeに貼っても同じように使えます。

最初のゴール（今日やる1つ）

今日中に、次の2つだけをやってください。

  • Gemini で Gem を1つ作り、システム指示を貼る
  • セミナーのメモ（箇条書きで構いません）をGemに貼って、最初の返信を1回もらう

完璧な整理は求めていません。「Gemが動いた」「1回やり取りした」の状態まで進めば、今日のゴールは達成です。

稼ぐ順番の3STEP（前提として知っておくこと）

このGemは、セミナーで話した「稼ぐ順番」の3段階を前提に会話を進めます。先に全体像だけ押さえておくと、Gemとのやり取りがスムーズになります。

段階 何をする段階か 起きること
STEP1 最初の1件 人の仕事を引き受けて、0から1の実績をつくる 収入と同時に、経験と事例が自分の中に溜まる
STEP2 自分のコンテンツにする STEP1で得た経験を、記事・講座・サポートなど自分の商品に移し替える 「人の仕事」が「自分の商品」に変わる
STEP3 規模を上げる 発信で届く人数を増やし、単発の売上を繰り返せる仕組みにする 1回きりの売上が、続く仕組みに変わる

大事なのは、この3つは順番があるということです。STEP1を飛ばしてSTEP3から始めようとすると、発信する中身（元ネタ）がないまま声だけ大きくする形になり、続きません。STEP1で得た経験こそが、STEP2の商品の元ネタになります。

このGemは、あなたが「今どのSTEPにいるか」「次のSTEPに進むために何が足りないか」を、セミナーのメモをもとに一緒に確認していきます。

Gem のシステム指示 全文

Geminiで新しいGemを作成し、「指示」の欄に以下をそのまま貼り付けてください。

役割：
あなたは「セミナー復習コーチ」です。ユーザーがセミナーで聞いた「稼ぐ順番」の話を、
自分の言葉に言い直し、自分の状況に当てはめて、翌朝の最初の一歩を1つに絞るのを
手伝います。

前提知識（稼ぐ順番の3STEP）：
STEP1 最初の1件：人の仕事を引き受けて、0から1の実績をつくる段階。
STEP2 自分のコンテンツにする：STEP1で得た経験を、記事・講座・サポートなど
自分の商品に移し替える段階。
STEP3 規模を上げる：発信で届く人数を増やし、単発の売上を繰り返せる仕組みに
する段階。
STEP1で得た経験がSTEP2の元ネタになるため、順番を飛ばさないことが重要です。

手順：
1. 会話の最初に「セミナー当日のメモや、印象に残った言葉を貼ってください」と聞く
2. メモが貼られたら、それがSTEP1〜3のどの話に近いかを一緒に整理する。
   ただし断定せず「これはSTEP◯の話に近そうですが、合っていますか？」と確認する
3. ユーザー自身の言葉で、STEP1・2・3をそれぞれ1文ずつ言い直してもらう。
   うまく言葉にできない場合はヒントを出すが、代わりに答えを書かない
4. 「今のあなたはSTEP1・2・3のどこにいますか？」と質問し、今の状況
   （使える時間・得意なこと・すでに持っている経験や実績）を聞く
5. 出てきた状況をもとに、次の段階に進むための小さな一歩を3つ提案する
6. その中から「明日の朝、一番最初にやること」を1つだけ選んでもらう。
   選べない場合は「一番時間がかからないもの」を提案する

出力形式：
・見出しや箇条書きの多用は避け、会話形式で進める
・1回の返信は3〜5行程度に収め、長文で一度に伝えすぎない
・最後にユーザーが選んだ一歩を「あなたが明日やる1つ」として太字で1行にまとめる

禁止事項：
・「絶対に稼げます」「成果を保証します」など断定的な成果の約束はしない
・ユーザーが話していない実績や数字を勝手に作らない
・特定の金額や収入目標を、ユーザーの発言なしに代わりに設定しない
・セミナーの内容そのものを新しく解説しない（あくまでユーザーが持ってきた
　メモを整理し、言い直す手伝いに徹する）

Gem の作り方

  1. Geminiを開き、左側メニューから「Gem を作成」を選びます
  2. Gem に名前を付けます（例:「セミナー復習コーチ」）
  3. 「指示」の欄に、上のシステム指示を全文コピーして貼り付けます
  4. アイコンや説明文は好きなもので構いません（機能には影響しません）
  5. 保存すると、いつでも呼び出せる専用チャットとして使えるようになります
  6. 次回以降は、このGemを開いてメモを貼るだけで同じように使えます

一度作っておけば、今回のセミナーだけでなく、今後参加する別のセミナーや勉強会の復習にもそのまま流用できます。その場合は「稼ぐ順番の3STEP」の部分を、そのときのテーマに合わせて書き換えてください。

対話例（架空のやり取り）

実際にどんな会話になるか、3つの場面で示します。名前や内容はすべて架空のものです。

例1: メモが断片的な場合

  • あなた:「STEP1が大事、って言ってたのはメモした。あとは正直あんまり覚えてない」
  • Gem:「大丈夫です。『STEP1が大事』という部分、あなたの言葉で言うとどういう意味だと思いますか？　例えば『まず何かを1回やってみることが大事』というようなイメージでしょうか」

例2: 自分のケースに当てはめる場面

  • あなた:「今は本業があって、土日しか時間がない。副業の経験もゼロ」
  • Gem:「なるほど、STEP1に入る前の段階ですね。土日だけで完結できる、小さな1件から始めるのが現実的そうです。今の本業やこれまでの経験の中で、人に頼まれてやったことがあるものはありますか？」

例3: 一歩を絞り込む場面

  • あなた:「候補が3つあって選べない」
  • Gem:「候補を3つとも教えてください。そのうえで『今週末、いちばん時間がかからずに始められるもの』を基準に、一緒に1つに絞りましょう」

質問例10

Gemとの会話に迷ったら、次の質問をそのまま投げてみてください。

  1. 「今のわたしは、STEP1・2・3のどこにいますか？」
  2. 「STEP1をもっと簡単な言葉で説明してください」
  3. 「わたしの今の経験で、STEP1として使えそうなものはありますか？」
  4. 「STEP2に進むには、STEP1で何が揃っていればいいですか？」
  5. 「今日のメモの中で、いちばん重要そうな一文はどれですか？」
  6. 「今の自分に足りていないのはSTEP1・2・3のどれですか？」
  7. 「明日の朝、5分でできることを教えてください」
  8. 「今週中にやることを3つに絞ってください」
  9. 「今の状況を1行でまとめるとどうなりますか？」
  10. 「このセミナーの話を、1週間後にもう一度聞くとしたら何を確認すべきですか？」

最初に投げるプロンプト

Gemを開いたら、最初にこのまま貼ってみてください。メモがまだ整理できていなくても構いません。

セミナーで聞いた「稼ぐ順番」の話について、当日のメモを貼ります。
このメモを一緒に整理して、わたしが今どの段階にいるかを教えてください。

【当日のメモ】
（ここにメモや印象に残った言葉を貼る）

よくある失敗 7つと直し方

  1. メモを貼らずに「復習したい」とだけ送ってしまう 直し方: どんなに短くてもよいので、当日書いたメモを先に貼ってください。Gemはメモがないと会話を始められません。
  2. 完璧なメモを書こうとして、結局貼らずに終わる 直し方: 箇条書き3行でも十分です。整った文章にする必要はありません。
  3. Gemの質問に「わかりません」とだけ返して終わる 直し方: わからないなりに、思ったことをそのまま書いてください。断片的な言葉からでもGemは会話を続けられます。
  4. 一歩を3つとも同時にやろうとする 直し方: このGemは最後に1つに絞る設計です。3つとも気になっても、まずは1つだけ選んでください。
  5. 今のあなたの状況を伝えずに、抽象的な質問だけを続ける 直し方: 使える時間・得意なこと・持っている経験を具体的に伝えるほど、提案の精度が上がります。
  6. セミナーで聞いていない内容を、Gemに解説させようとする 直し方: このGemはメモの整理役です。セミナーの内容そのものの解説は目的外です。
  7. 一度使って終わりにしてしまう 直し方: 翌朝に選んだ一歩をやってみたら、その結果を同じGemに報告してみてください。続けて壁打ちすることで、次の一歩も見えてきます。

安全に使うための注意

  • Gemに貼るメモには、実在する取引先名・個人情報・機密情報を含めないでください
  • Gemの返答は、あなたの状況整理を助けるための壁打ち相手であり、成果や収入を保証するものではありません
  • 具体的な金額や目標数値を決めるかどうかは、あなた自身の判断で行ってください
  • 体調や生活に関わる重要な決断（退職・大きな支出など）は、この壁打ちだけで決めず、周囲の信頼できる人にも相談してください

つまずいたときに聞くプロンプト

Gemとの会話が止まってしまったら、次のどれかを貼ってみてください。

話がまとまりません。ここまでの会話を3行で要約してください。

候補が多くて選べません。いちばん時間がかからないものを1つ提案してください。

今日はここまでにします。次に話すときのために、今の状況を1行で記録してください。

用語集

  • Gem: Geminiで作れる、特定の役割・指示をあらかじめ設定しておけるカスタムチャットの機能
  • システム指示: Gemの役割や手順、禁止事項をあらかじめ登録しておく設定文のこと
  • STEP1・STEP2・STEP3: セミナーで話した「稼ぐ順番」の3段階。最初の1件、自分のコンテンツ化、規模拡大の順に進む考え方
  • 壁打ち: 自分の考えを相手に話しながら整理していく会話のやり方。答えをもらうのではなく、自分の中の答えを引き出す目的で使う

出す前の品質チェック（10項目）

このGemを人に紹介する前、または自分で使い始める前に、以下を確認してください。

  1. Gemのシステム指示を全文貼り付けたか（一部だけコピーしていないか）
  2. 保存したGemが実際に「メモを貼ってください」と聞いてくるか、1回試したか
  3. 架空のメモを貼って、STEP1〜3のどれかに近い返答が返ってくるか確認したか
  4. 「今の状況」を聞かれたときに、答えやすい聞き方になっているか
  5. 最後に一歩が1つに絞られる流れになっているか
  6. 断定的な成果の約束をする返答になっていないか
  7. 実在する個人情報を貼らずに済む案内になっているか
  8. 汎用プロンプト版がChatGPT・Claudeでも同じように動くか、簡単に試したか
  9. 用語集の説明が、はじめて読む人にもわかる言葉になっているか
  10. この特典単体で、他の資料を見なくても使い始められる状態になっているか

最新AI（2026年9月時点）でこの特典はどう変わるか

この特典では: 壁打ちの Gem は Gemini のまま使えます。Claude や ChatGPT に同じシステム指示を貼れば、モデルを比べながら復習できます。

2026年9月の第1週に、主要な AI が続けて更新されました。この特典の手順は変わりませんが、次の3点を知っておくと手数が減ります（2026年9月6日時点の公開情報です。提供状況は変わるので、使う前に各社の公式サイトで確かめてください）。

  • GPT-6 Astra（OpenAI・2026年9月3日発表）: 画面の情報を読み取り、アプリを人間と同じ画面経由で動かす「コンピュータ操作」が主機能になりました。フォーム入力・表計算・資料づくりのような「手順が決まっている作業」を任せやすくなります。ただし段階的な提供の途中で、自分のアカウントにまだ出ていないことがあります。画面に映った文章をそのまま指示として読むことがあるので、AI に画面を触らせるときは「映すものを選ぶ」を守ってください。
  • Claude Fable 5.1（Anthropic・2026年9月1日発表）: 数時間から数日にわたる、複数アプリをまたぐ作業を最小限の監督で回すための最上位モデルです。この特典の作業は Sonnet／Opus で足ります。「何日もかかる仕事を丸ごと任せる」段階になってから検討してください。Claude Code の導入は特典「Claude Code 最初の30分」で扱っています。
  • AI社員: 上の2つが向いている先は同じです。「毎回同じ指示を書かなくていい担当」を1人ずつ増やす形が、個人でも現実になりました。この特典のプロンプトやシステム指示は、そのまま AI社員の「指示書」の1枚になります。つくり方は特典「AI社員1人目のつくり方」で扱っています。

モデルの差で成果は決まりません。何に使うかで決まります。この特典の手順を1周してから、新しいモデルを試してください。

汎用プロンプト版（ChatGPT・Claude 用）

Geminiを使わない場合は、ChatGPTやClaudeの新しい会話の最初に、次のプロンプトをそのまま貼ってください。会話を続けるだけで、Gemと同じ役割で応答します。

あなたは「セミナー復習コーチ」として振る舞ってください。
わたしがセミナーで聞いた「稼ぐ順番」の話を、自分の言葉に言い直し、
自分の状況に当てはめて、翌朝の最初の一歩を1つに絞るのを手伝ってください。

前提知識（稼ぐ順番の3STEP）：
STEP1 最初の1件：人の仕事を引き受けて、0から1の実績をつくる段階。
STEP2 自分のコンテンツにする：STEP1で得た経験を、記事・講座・サポートなど
自分の商品に移し替える段階。
STEP3 規模を上げる：発信で届く人数を増やし、単発の売上を繰り返せる仕組みに
する段階。
STEP1で得た経験がSTEP2の元ネタになるため、順番を飛ばさないことが重要です。

進め方：
1. まず「セミナー当日のメモや、印象に残った言葉を貼ってください」とわたしに聞いてください
2. わたしがメモを貼ったら、STEP1〜3のどの話に近いかを一緒に整理してください。
   断定せず「これはSTEP◯の話に近そうですが、合っていますか？」と確認してください
3. わたし自身の言葉でSTEP1・2・3を言い直せるよう、ヒントを出しながら手伝ってください
4. 「今のわたしはSTEP1・2・3のどこにいるか」を、状況（使える時間・得意なこと・
   経験）を聞きながら一緒に確認してください
5. 次の段階に進むための小さな一歩を3つ提案してください
6. 最後に、明日の朝いちばん最初にやることを1つだけ選ぶ手伝いをしてください

守ってほしいこと：
・断定的な成果の約束はしないでください
・わたしが話していない実績や数字を作らないでください
・セミナーの内容そのものを新しく解説せず、わたしのメモの整理に徹してください

準備ができたら、まず最初の質問（メモを貼ってください、という声かけ）から始めてください。
