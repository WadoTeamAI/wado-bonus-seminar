お客様の声 採掘プロンプト

レビュー・コメント・アンケートの中に、あなたが書くよりも強く刺さる言葉がすでにあります。この特典は、その言葉を掘り当てて、note・Brainの記事、Instagramの投稿、Xの投稿にそのまま使えるようにする採掘プロンプトです。

はじめに

こんにちは、わどです。

コピーを書くとき、多くの人がやってしまう失敗があります。それは「自分の頭で、かっこいい言い回しをひねり出そうとすること」です。ひねり出した言葉は、たいてい平均的で、誰にも刺さりません。

一方で、あなたの見込み客はすでに、あなたが書きたい言葉を口にしています。レビューの中で、コメント欄で、アンケートの自由記述欄で。ただ、それは散らばっていて、誰も拾いに行っていないだけです。

この特典は、その散らばった本音を拾い上げ、note・Brainの記事、Instagramのストーリーズ、Xの投稿にそのまま使える形に変えるプロンプト集です。コピーは書くものではなく、掘るものだと考え方を変えるところから始めます。

この特典の進め方

順番に読んでください。掘り方を知らずに分類だけ真似ると、ノイズだらけの本音を集めることになります。

  1. 「考え方」を読む(5分)。なぜ自分で書くより、掘るほうが強いのかを理解します。
  2. 「プロンプト全文」をコピーしておく(2分)。抽出用と仕分け用、Gem用の3つです。
  3. 「使い分けの判断」で、どの場面でどのプロンプトを使うかを整理します。
  4. 「最初に投げるプロンプト」を、実際に手元にある1件のレビューやコメントに使ってみます。
  5. 詰まったら「うまくいかないときの直し方」と「よくある失敗7つと直し方」に戻ってきてください。

全体で、読む時間は15分、実際に手を動かす時間は15分です。今日中に、1つは本音のフレーズが手元に残ります。

最初のゴール(今日やる1つ)

今日、これだけやってください。

  • 手元にある、お客様や見込み客の生の言葉を1つ用意する(過去にもらったDM、コメント、アンケートの自由記述、各種プラットフォームのレビュー、どれでも構いません)。
  • 「最初に投げるプロンプト」をそのままAIに入力する。
  • 出てきた抽出フレーズの中から1つを選び、次に書くnote記事かX投稿の冒頭に使ってみる。

これだけで、「自分で考えるより、掘るほうが速い」という感覚が体に入ります。

考え方(なぜその書き方が効くか)

コピーが刺さらない理由は、たいてい「自分の言葉で書いているから」です。

自分の頭で考えた言い回しは、どうしても「プロっぽく」「きれいに」なろうとします。ところが、見込み客が実際に悩んでいるときに使う言葉は、もっと生々しく、もっと具体的です。「伸び悩む」ではなく「もう何も変わらない気がする」。「不安」ではなく「このまま何も残らずに終わる気がする」。この生々しさこそが、読み手に「これ、私のことだ」と思わせます。

ここでAIの使い方を1つ変えてください。AIに「文章を作らせる」のではなく、「人の本音を掘らせる」道具として使います。AIに文章生成を頼むと、平均的でなめらかな言葉が返ってきます。逆に、すでにある生のテキストから本音を抜き出す作業をAIに頼むと、あなたが自分では思いつかなかった強烈なフレーズが出てきます。

コピーライティングの世界でよく引用される事例に、あるリハビリ施設の話があります。プロが書いた「あなたの依存症は、ここで終わります」という広告文から、レビューの中にあった「もし自分にリハビリが必要だと思っているなら、必要なんです」という一文に差し替えたところ、クリック率が大きく伸びたと言われています。プロが練った言葉より、悩んでいる本人の言葉のほうが、同じ悩みを持つ人に強く届いたということです。

同じように、あるプロジェクト管理ツールは、「プロジェクト管理を、シンプルに」という説明的なコピーから、顧客インタビューで出てきた「髪の毛に火がついたような忙しさ」という表現をヒントに、「プロジェクト管理なんて、大惨事だ」という言い切りに変えて話題になった、という話もよく紹介されます。きれいな言葉を、汚い本音に翻訳し直したわけです。

ここで大事なのは「翻訳しない勇気」です。見込み客が使っている言葉が多少乱暴でも、隠語のようなものでも、きれいな日本語に直さずそのまま使うことで、「わかってくれている」という感覚が生まれます。

日本で本音を掘るときは、次の3つの壁を知っておいてください。

  1. レビューの多くは評論: 「配送が早かった」「構成が読みにくい」など、悩みの吐露ではなく商品評価になりがちです。悩みが出やすい別の場所(コメント欄、DM、アンケートの自由記述)も探してください。
  2. 特典目当ての高評価が混じる: 「星5をつけたら特典」文化があるジャンルでは、絶賛コメントの多くがノイズです。星3〜4のレビュー、購入直後ではなく時間が経ってからのレビューのほうが、本音が出やすい傾向があります。
  3. 質問サイトは量が多くても質が低い: 回答ではなく、質問文そのものに出てくる感情の言葉(「つらい」「もう無理」など)に絞って探すと、効率が上がります。

プロンプト全文(型ごと・コピーして使える形)

3つの道具を渡します。1つ目は生テキストから本音を抜き出す抽出用、2つ目はその本音を9つの引き出しに仕分ける分類用、3つ目はGemに常駐させる完成形のシステム指示です。

1. 抽出プロンプト

あなたはコピーライターではなく、リサーチャーです。
以下のテキスト(レビュー・コメント・DM・アンケートの自由記述)から、
書き手が「自分の言葉」で語っている痛み・不満・願望を抽出してください。

【ルール】
- プロっぽい言い換えはせず、原文のまま抜き出す
- 個人が特定できる情報(名前・連絡先・固有のハンドル名など)は伏せ字にする
- 該当する箇所がなければ「該当なし」と正直に答える。無理に見つけない

【出力】
- 原文引用:「…」
- 何についての痛み・不満・願望か(1行で)
- この言葉をそのまま使うなら、どんな見出しに向いているか(案を1つ)

【対象テキスト】
〔ここにレビュー・コメント・DM等の原文を貼る〕

2. 9つの引き出しに仕分けるプロンプト

本音は、次の9つのどれかに当てはまることが多いです。分類しておくと、あとで「この悩みの人にはこの言葉」と使い分けられるようになります。

引き出し 見分け方
1.怒り 相手や商品を名指しで責めている
2.諦め 「どうせ」「もう」など、自分を責めて閉じている
3.悩みの生の言葉 状態を表す素の名詞・動詞・形容詞
4.反応した約束 「これいいな」「試したい」と思った言い回し
5.胡散臭さ 「本当に?」「嘘くさい」と警戒した理由
6.他への不満 既存のサービス・他の商品への具体的な不満
7.信じた証拠 「これがあったから信じた」という言及
8.離脱した言葉 聞いた瞬間に「自分には関係ない」と感じた専門用語
9.腑に落ちた例え 「要は◯◯みたいなもの」という理解の瞬間 
あなたはリサーチャーです。ライターではありません。
以下のテキストから、書き手が「自分の言葉」で語っている本音を抽出し、
次の9つの引き出しに分類してください。

【9つの引き出し】
1.怒り 2.諦め 3.悩みの生の言葉 4.反応した約束 5.胡散臭さ
6.他への不満 7.信じた証拠 8.離脱した言葉 9.腑に落ちた例え

【ルール】
- 該当する引き出しすべてに分類する(1つの発言が複数に当てはまってよい)
- 該当がなければ「該当なし」と正直に答える。無理に埋めない
- 各該当につき、原文引用(改変禁止)と抽出フレーズ(コピーに使える名詞・動詞・形容詞)を分けて出す
- プロっぽい言い換え・きれいな日本語への翻訳は禁止。生々しさを残す
- 個人が特定できる情報は伏せ字にする

【出力】
- 引き出し: (該当するもの。複数可)
- 原文引用:「…」
- 抽出フレーズ:「…」「…」
- 発言者の想定(初心者/経験者など、推測でよい)

【対象テキスト】
〔ここに複数件のレビュー・コメント等をまとめて貼る〕

3. Gemのシステム指示(そのまま貼って使える完成形)

Geminiの「Gemを作る」画面の指示欄に、次をそのまま貼ってください。

あなたは「お客様の声採掘リサーチャー」です。ライターではありません。
文章を美しく仕上げることが役目ではなく、貼られたテキストの中から
書き手の本音(痛み・不満・願望・警戒・納得の瞬間)を、
原文のまま拾い上げることが役目です。

【役割】
ユーザーがレビュー・コメント・DM・アンケートの自由記述を貼ってきたら、
その中から本音のフレーズを抽出し、9つの引き出し
(怒り/諦め/悩みの生の言葉/反応した約束/胡散臭さ/他への不満/
信じた証拠/離脱した言葉/腑に落ちた例え)に仕分けて返してください。

【手順】
1. 貼られたテキストを1件ずつ読む(複数件あれば全件)。
2. 各件から、本音と呼べる一文または短いフレーズを見つける。
3. 見つけたフレーズを、該当する引き出しに分類する(複数該当を許容)。
4. 原文引用と、コピーに転用できる抽出フレーズを分けて示す。
5. 該当が見つからない件は「該当なし」と正直に答える。

【出力形式】
各件について、
- 引き出し
- 原文引用(改変禁止)
- 抽出フレーズ(名詞・動詞・形容詞。プロっぽい言い換え禁止)
- コピー案(この抽出フレーズを見出しに使うなら、という1案)
の4項目で返してください。

【禁止事項】
- 原文を勝手にきれいな日本語に直さない(生々しさが本音の価値です)
- 個人が特定できる情報(氏名・連絡先・固有のハンドル名)は伏せ字にする
- 本音が見当たらないのに、無理やり何かを作り出さない
- 「必ず効果があります」のような断定的な効能の保証はしない

使い分けの判断

3つの道具、どれを使うかは次の基準で決めます。

状況 使う道具
1件のレビュー・コメントから、今すぐ1フレーズ欲しい 抽出プロンプト
10件以上まとまった声があり、傾向を把握したい 9つの引き出しプロンプト
毎週・毎月、継続してお客様の声を拾いたい Gemを作って常駐させる

件数が少ないうちは抽出プロンプトで十分です。声が溜まってきたら、9つの引き出しで仕分けることで、「この悩みの人にはこの言葉が効く」という自分だけの言葉の在庫が育っていきます。

判断に迷ったら、「この作業を来月も繰り返すか」を自分に聞いてください。1回きりなら抽出プロンプト、繰り返すならGemを作って毎回同じ質で仕分けてもらうほうが早くなります。

うまくいかないときの直し方

型どおりにプロンプトを使っているのに、良いフレーズが出てこないときは、次を疑ってください。

  • 「該当なし」ばかり返ってくる: そもそも対象のテキストが評価や感想であって、悩みの吐露になっていない可能性があります。レビューだけでなく、コメント欄やDM、アンケートの自由記述欄など、より本音が出やすい場所を探してください。
  • 抽出フレーズがきれいすぎる: AIが親切心で言葉を整えてしまっています。「原文のまま」「プロっぽい言い換え禁止」を、プロンプトの最初にもう一度書き直して念押ししてください。
  • 同じような当たり障りのないフレーズしか出ない: 高評価ばかりを対象にしている可能性があります。星3〜4の評価や、購入から時間が経ってからの声を優先して集め直してください。
  • 本音は拾えたが、どこにも使い道が思いつかない: 抽出フレーズだけを見ても、使い道は浮かびにくいものです。9つの引き出しに仕分けたうえで、今書こうとしている記事や投稿のテーマに近い引き出しから選んでください。

本音の採掘は、量を集めるほど精度が上がります。1件で判断せず、最低でも5件は集めてから傾向を見てください。

最新AI(2026年9月時点)での書き方の変化

2026年9月3日に、複数の作業工程をまたいで進められる新しいモデル(GPT-6 Astra)が発表されました。文書の作成だけでなく、画面を読み取って操作する機能も含んだモデルとして紹介されています(取得日 2026-09-06)。ただし段階的な提供の途中で、あなたのアカウントにまだ表示されていない可能性があります。

お客様の声の採掘という作業にとって、この変化が意味することが1つあります。レビューサイトやコメント欄を、AIが画面越しに見て回り、テキストを集めてくる作業まで任せられる可能性が出てきたということです。ただし、画面に表示されているものを、AIが指示だと誤って読み取ってしまう可能性が指摘されています。見せてよい画面だけを見せる、という基本は変わりません。

抽出や仕分けそのものの考え方(原文のまま抜き出す、プロっぽく直さない、リサーチャーとして使う)は、使っているのがChatGPTでも、Geminiでも、Claudeでも変わりません。特定のツールの新機能に頼らなくても、この特典のプロンプトはそのまま動きます。

なお、複数のAIに同じ作業を任せて、比較しながら使い分けたい方は、「AIツール地図」を先にご覧ください。今、何が使えて、何にまだ手を出さなくてよいかが整理できます。

次の一手

この特典は、「稼ぎ方より、稼ぐ順番」でいうSTEP2(コンテンツ商品をつくる)とSTEP3(SNS・ローンチで届ける)の両方を底上げする、言葉の在庫をつくる特典です。抽出したフレーズはnote・Brainの記事の書き出しに、9つの引き出しで仕分けた本音はInstagramのストーリーズやXの投稿の見出しに、そのまま使えます。

本音の言葉を拾えるようになったら、次は「どの本音を、どの順番で、誰に届けるか」です。面談では、あなた専用の1枚(特注のロードマップ)を一緒に作ります。

最初に投げるプロンプト

はじめて使うときは、いきなり9つの引き出しに仕分けようとせず、まず1件だけ抽出することから始めてください。

以下は、わたしの見込み客(または既存のお客様)が実際に書いた言葉です。
この中から、いちばん感情が強く出ている一文を1つだけ選んでください。

選んだら、次の3つを教えてください。
1. その一文(原文のまま)
2. なぜその一文を選んだか(感情の強さ・具体性の観点で)
3. この一文をそのまま見出しやリード文に使うなら、どんな形にできるか(1案)

【対象テキスト】
〔ここに1件分の原文を貼る〕

1件だけに絞ることで、「本音を拾う」という感覚をつかんでから、量を増やしていけます。

よくある失敗 7つと直し方

  1. きれいな感想文を対象に選んでしまう → 直し方: 星5の絶賛レビューではなく、星3〜4の少し複雑な感情が混じったレビューを探す。

  2. 抽出したフレーズを、そのまま使わずに書き直してしまう → 直し方: 最初の1回は、あえて一字一句そのまま見出しに使ってみる。生々しさが伝わるかを体感する。

  3. 1件だけ見て「大した本音はない」と諦めてしまう → 直し方: 最低5件は集めてから判断する。強いフレーズは、たいてい数件に1件しか出てこない。

  4. 本音を掘ったのに、どこにも記録せず忘れてしまう → 直し方: 抽出フレーズと、それがどの引き出しに当てはまるかを、簡単な表に貯めていく。

  5. 個人が特定できる情報をそのまま貼ってしまう → 直し方: 名前・連絡先・固有のハンドル名は、貼る前に自分の手で伏せ字にしておく。

  6. すべての声を1つの引き出しに詰め込もうとする → 直し方: 1つの発言が複数の引き出しに当てはまってよいと割り切る。無理に1つに絞らない。

  7. 本音を拾って満足し、実際の投稿や記事に使わない → 直し方: 「最初のゴール」で決めたとおり、拾った週のうちに1つは実際の文章に使う。

安全に使うための注意

  • 貼るテキストに含まれる氏名・連絡先・具体的な契約金額などは、貼る前に自分の手で伏せ字にしてください。AIに読み込ませた内容が、学習や記録に使われる可能性がある前提で扱ってください。
  • 抽出した本音の言葉を使うときは、「必ず効果がある」「誰にでも当てはまる」といった断定は避けてください。1人の本音を、全員の代弁のように扱わないことが誠実さです。
  • 画面を読み取って操作するタイプのAI機能(2026年9月時点で登場し始めています)を使う場合、画面に表示された内容をそのまま指示として誤って読み取ることがあると報告されています。見せる画面は選んでください。
  • 公開前には、抽出したフレーズが本当に事実に基づいているか(実在するお客様の声か、AIが作り出したものではないか)を、必ず人の目で確認してください。

つまずいたときに聞くプロンプト

「本音はいくつか拾えたけれど、どれを使えばいいか分からない」となったら、これをそのまま使ってください。

以下は、拾った本音のフレーズのリストです。
今からわたしが書こうとしているのは〔note記事 / Instagramの投稿 / Xの投稿〕で、
テーマは〔テーマを書く〕です。

このテーマに、いちばん合っているフレーズを1つ選び、
なぜそれを選んだのかを教えてください。

【本音のフレーズのリスト】
〔ここに拾ったフレーズを箇条書きで貼る〕

選ばれた理由を読むことで、自分でも「どの本音が、どの場面に効くか」の勘所がつかめてきます。

用語集

  • 本音採掘(レビューマイニング): レビュー・コメント・アンケート等から、書き手が自分の言葉で語った痛み・不満・願望を抜き出すこと。
  • 翻訳しない勇気: 見込み客の生々しい言葉を、きれいな日本語に直さずそのまま使う姿勢。
  • 9つの引き出し: 拾った本音を、怒り・諦め・悩みの生の言葉・反応した約束・胡散臭さ・他への不満・信じた証拠・離脱した言葉・腑に落ちた例え、の9種類に仕分ける型。
  • 抽出フレーズ: 原文の中から抜き出した、コピーにそのまま転用できる名詞・動詞・形容詞。
  • リサーチャーとしてのAI: 文章を作らせるのではなく、すでにあるテキストから事実や本音を拾わせる使い方。
  • 離脱語彙: 聞いた瞬間に「自分には関係ない」と感じさせる専門用語。発信では避けるべき言葉。

出す前の品質チェック(10項目)

公開する前に、この10項目を確認してください。
