第二の脳のつくり方 入門

メモが「書いて終わり」で消えていく状態から、「書けば書くほど、あなたのAIが賢くなる」状態に変えます。難しいツールの操作ではなく、3つの層に分けて置くという考え方だけを扱います。

はじめに

わどです。この特典は、AIで収益を上げていくうえで、いちばん最初に効いてくる土台の話です。土台というのは、ノートを書く場所ではなく「どこに何を置くか」の考え方そのものです。

多くの人は、AIに何かを頼むたびに、状況の説明からやり直しています。noteの記事ネタも、Instagramのストーリーズで使った言い回しも、Xで反応が良かった投稿も、それぞれ別のメモアプリや頭の中に散らばっているからです。これでは、AIに聞かれるたびに一から思い出す作業が発生し、思い出せなかった分だけ、AIの提案は的外れになります。

「第二の脳」というのは、この散らばりを1か所にまとめて、AIがいつでも読める状態にしておく仕組みのことです。ツールは何でも構いません。Notionでも、NotebookLMでも、別の特典で扱っているObsidianでも同じ考え方が通用します。この特典では、ツールの操作手順ではなく「何を、どの層に、どう置くか」という判断の軸だけを扱います。具体的な操作画面が欲しい方は、別の特典「第二の脳 Obsidian初期設定テンプレ」を合わせて使ってください。

第二の脳が育つと、次のようなことができるようになります。

  • noteの新しい記事を書くとき、過去に書いた記事のトーンや言い回しをAIに参照させて、あなたらしい文章を最初の一稿から出させる
  • Instagramのストーリーズ台本を作るとき、過去に反応が良かった構成をAIに読ませて、同じ型で量産させる
  • Xの投稿を作るとき、あなたが繰り返し言っている主張(あなたの原則)をAIに渡して、ブレない発言を作らせる

これらはすべて、メモが「1か所に、AIが読める形で」置かれているから可能になります。逆に言えば、置き方が整っていなければ、AIにどれだけ良い指示を出しても、参照できる材料がなく、当たり障りのない一般論しか返ってきません。

この特典の進め方

上から順番に読んでください。2章の「3層で迷わない置き方」が考え方の中心です。ここを理解してから3章のテンプレートを自分の言葉で埋めると、迷わずに続けられます。前提となる道具は、メモを書ける場所(Notion、NotebookLM、Obsidianなど何でも可)が1つあることだけです。

最初のゴール(今日やる1つ)

今日のゴールは1つだけです。

今、頭の中や色々なアプリに散らばっているメモを3つだけ選び、2章の3層のどこに置くかを判断して、実際に1か所に移す。

全部を一気に整理する必要はありません。3つだけで構いません。「判断して、動かす」という一連の動きを、今日1回だけ体験してください。

1. 何を任せるか(人とAIの線引き)

第二の脳づくりで、人がやることとAIに任せることを最初に分けておきます。ここを曖昧にしたまま始めると、AIに「全部読んで、いい感じにまとめて」と丸投げして、結局使わないメモの山ができます。

作業 人がやること AIに任せられること
メモを書く 気づいた瞬間に、自分の言葉で書く 書きなぐった文章を、後から整った形に整える
どの層に置くか判断する 最初のうちは自分で判断する(3層の基準は2章) 判断に迷ったメモを見せて、どちらに近いか意見をもらう
記事・投稿を作る 最終的に出す・出さないを決める 第二の脳の中身を読み込んで、たたき台を作る
週次の見直し 見直す時間そのものは自分で確保する 溜まったメモを層ごとに要約して、見直しやすくする

人が持つべき役割は「判断の基準を握ること」です。AIに渡してよいのは「その基準に沿って作業を進めること」です。この線引きが崩れると、AIが勝手に分類した結果、あなたが後で「これはどこに置いたんだっけ」と探し直す羽目になります。

2. つくり方の手順(3層で迷わない置き方)

第二の脳が機能しなくなる最大の原因は、分類のルールが複雑すぎることです。フォルダを10個も20個も作ると、メモを書くたびに「どこに入れよう」と考える時間が発生し、その手間がストレスになって、そのうち書かなくなります。

そこで、置き場所は次の3層だけに絞ります。

層1: 受け皿(なんでも置いていい場所)

気づいたこと、思いついたアイデア、あとで読みたい記事のリンク、ふと出てきた不満。判断せずに、そのまま全部ここに投げ込みます。分類は後回しでよい、というのがこの層の唯一のルールです。ここに置く基準は「今すぐどこに置くか判断できない」の一言だけです。

層2: 資料・事実の棚(ジャンルごとに整理する場所)

外部から得た情報、リサーチした事実、うまくいった投稿の実例、講座や勉強会で聞いた話。これらは「あなたの意見」ではなく「外の世界の事実や資料」です。ジャンルごとの棚(noteのネタ帳、SNSの型集、業界動向など)に分けて置きます。層1に投げ込んだメモのうち、事実や資料の性質を持つものは、週次の見直し(4章)でここに移します。

層3: 自分の原則(短く言い切れる教訓)

「これは自分の言葉でこう言い切れる」というところまで煮詰まった考えだけを置く層です。1つのメモには1つの考えだけを書きます。長い日記のようなメモではなく、「Xの冒頭は結論から書く。理由は最初の1行で読むかどうかが決まるから」のような、短く再利用できる形にします。この層が厚くなるほど、AIに渡したときの「あなたらしさ」が濃くなります。

3層の見分け方に迷ったら、次の3問で判断します。

  1. まだ判断できない、とりあえず置いておきたいだけ → 層1
  2. 外の情報・事実・実例で、自分の意見はまだ入っていない → 層2
  3. 自分の言葉で「こうだ」と言い切れる、短い一文にできる → 層3

迷って止まるくらいなら、いったん層1に置いてください。層1から層2・層3への移動は、後からいつでもできます。逆に、最初から層3に無理やり分類しようとすると、まだ煮詰まっていない考えを言い切ってしまい、後で読み返したときに使えない教訓が残ります。

3. 指示書・シートの全文

ここからは、コピーしてそのまま使えるテンプレートです。空欄は自分の言葉で埋めてください。

3層 振り分けシート

新しいメモが増えるたびに、この表の質問に1つずつ答えて、置き場所を決めます。

【新しいメモの振り分け】

メモの内容:
(ここに書いたメモをそのまま貼る)

Q1. まだ判断できない、とりあえず置いておきたいだけか?
YES → 層1(受け皿)に置く。以下は答えなくてよい。
NO → Q2へ

Q2. 外の情報・事実・実例で、自分の意見はまだ入っていないか?
YES → 層2(資料・事実の棚)に置く。ジャンル名: ___________
NO → Q3へ

Q3. 自分の言葉で「こうだ」と1文で言い切れるか?
YES → 層3(自分の原則)に置く。関連する既存のメモ: ___________
NO → 言い切れるところまで、もう少し自分の中で考えてから置く

AIに読ませる「第二の脳 紹介文」テンプレート

第二の脳をAIに読ませるときの、最初の1枚です。ここに書いた内容を、AIとの会話やGem・Skillの設定の冒頭に渡します。

私はこういう活動をしています。
(1〜2文で、今やっている発信・商品・仕事を書く)

今のゴールはこれです。
(3か月以内に達成したいことを1つ)

私の言葉づかい・トーンはこうです。
(丁寧語か、くだけた口調か。よく使う言い回しがあれば書く)

私が繰り返し言っている考え(層3の原則から、3〜5個選んで貼る):
・
・
・

このメモを読んだうえで、次のことをお願いします。
(依頼したい作業をここに書く。例: noteの記事のたたき台を作ってほしい)

守ってほしいルール:
・私が実際に経験していないことを、経験したかのように書かない
・数字や実績は、ここに書いていないものを勝手に作らない
・出てきた文章は、必ず私が確認してから使う前提で作る

週次見直しシート

4章の週次の見直しで使う、記入用のテンプレートです。

【第二の脳 週次見直し】

日付:

今週、層1に投げ込んだメモの数:

そのうち、層2に移したもの:
・

そのうち、層3に移したもの(自分の原則として言い切れたもの):
・

来週も層1に残しておくもの(まだ判断できないもの):
・

来週、意識して増やしたい層(1・2・3のどれか):

4. 運用の型(週次の見直し)

第二の脳は、作った日が完成日ではありません。置き続けて、定期的に見直して、初めて育ちます。週に1回、15分だけ時間を取ってください。

見直しの手順は次の3ステップです。

  1. 層1(受け皿)に溜まったメモを、上から順に読み返す
  2. 「3層 振り分けシート」の3問を、1つずつ当てて、層2か層3に移すか、層1に残すかを決める
  3. 週次見直しシートに、今週の動きを1行ずつ記録する

このとき、AIに手伝わせられる部分は「溜まったメモを要約して、似た内容ごとにグループ分けする」ところまでです。どのグループを層2に、どのグループを層3に移すかの最終判断は、人が持ちます。AIの要約は、判断を速くするための材料であって、判断そのものではありません。

見直しを溜めすぎると、1回あたりの負担が重くなって、結局やらなくなります。15分で終わる量に保つには、層1に置くメモの粒度を小さくすることです。1つのメモに複数の話題を詰め込まず、話題ごとに分けて置いてください。

5. 最新AI(2026年9月時点)での変わり目

2026年9月、OpenAIから新しいモデル「GPT-6 Astra」が発表されました(取得日2026-09-06)。このモデルの特徴の1つが、画面の情報を読み取りながら、承認されたアプリを人間と同じ画面越しに操作できることです。段階的な提供が進んでいる段階で、使える範囲はアカウントによって差があります。

第二の脳との関係で言うと、将来的には「AIが自分でメモアプリの画面を開き、溜まったメモを見て、層を移動させる」といった作業を、AIが直接操作して進められるようになっていく方向にあります。ただし、この種の機能には注意点も指摘されています。画面に表示されている情報が、意図せず操作の指示として読み取られてしまう可能性があるという点です。つまり、AIに画面を触らせるときは、映すものを選ぶ必要があります。

現時点でできることは変わりません。層1から層2・層3への移動判断は人が持ち、AIには「要約」「グループ分けの提案」までを任せる、という4章の役割分担のままで問題ありません。AIに画面操作そのものを任せられる場面が増えても、この判断の線引きは変えないでください。

なお、AIに第二の脳を読ませたうえで、繰り返し発生する作業を専用の担当に任せたい場合は、別の特典「AI社員1人目のつくり方」で手順を扱っています。また、Claude Codeというツールを使ってVaultの中身をAIに常時読ませる形にしたい場合は、別の特典「Claude Code 最初の30分」を参照してください。

最初に投げるプロンプト

第二の脳の紹介文(3章のテンプレート)を埋め終えたら、まずはこのプロンプトで試してください。

これが私の第二の脳の紹介文です。

(3章の「AIに読ませる「第二の脳 紹介文」テンプレート」を埋めたものを貼る)

このメモを読んだうえで、私がよく使う言い回しと、繰り返し言っている考えを3つ、箇条書きで教えてください。
私自身が気づいていない癖があれば、それも教えてください。

ここでAIが挙げた内容が、あなたの自己認識とズレていたら、そのズレこそが層3に足りていない部分です。ズレを埋めるように、原則メモを1つ書き足してください。

よくある失敗 7つと直し方

  1. フォルダを最初から細かく作りすぎる → 3層以上に増やさない。迷ったら層1に置く
  2. 層1が溜まる一方で、一度も見直さない → 週次見直しをカレンダーに固定の予定として入れる
  3. 層3に、まだ煮詰まっていない長い文章を置く → 1メモ1原則。言い切れないなら層2に留める
  4. AIに分類そのものを丸投げする → 分類の最終判断は人が持つ(1章の線引き)
  5. 紹介文(第二の脳 紹介文テンプレート)を一度作って更新しない → 週次見直しのたびに、層3の変化を反映する
  6. 実績や数字を、記憶で紹介文に書いてしまう → 実際に確認できる数字だけを書き、不明なものは書かない
  7. ツール選びに時間をかけすぎて、書き始めない → どのツールでも3層の考え方は同じ。今使っているメモ帳から始めてよい

安全に使うための注意

  • クライアントや第三者の個人情報・連絡先を、第二の脳にそのまま書き込まないでください
  • パスワードやAPIキーなどの認証情報は、AIに読ませる前提の場所には置かないでください
  • 層3の原則メモに「必ず」「絶対」「誰でも」といった言い切りを混ぜないでください。AIが出す文章にもそのまま影響します
  • AIに画面操作を任せる機能を使うときは、画面に表示するものを事前に確認してください。表示された内容が、意図しない指示として読み取られる可能性があります(5章)
  • 出てきた文章やまとめは、必ず自分の目で確認してから使ってください。AIの出力をそのまま公開・配信しないこと

つまずいたときに聞くプロンプト

そのままコピーしてAIに聞いてください。

今、私は第二の脳の中身をこう分けようとしています。
【ここに、今悩んでいるメモの内容を書く】

層1・層2・層3のどれに近いか、理由つきで教えてください。
どれにも当てはまらない場合は、そう教えてください。

ここ1週間で私が書いたメモのうち、似た内容が繰り返し出てきているものがあれば教えてください。
それは、層3の原則にできそうか、意見を聞かせてください。

出す前の品質チェック(10項目)

  1. 置き場所は3層以内に収まっているか(細かく分けすぎていないか)
  2. 層1に溜まったメモを、少なくとも1回は見直したか
  3. 層3の原則メモが、1メモ1アイデアの粒度になっているか
  4. 紹介文(3章のテンプレート)を、少なくとも半分埋めたか
  5. 紹介文の中に、パスワードなど認証情報が入っていないか
  6. 紹介文の実績・数字が、実際に確認できるものだけになっているか
  7. 週次見直しをカレンダーの固定予定に入れたか
  8. AIに読ませたあと、出てきた要約が実態とズレていないか確認したか
  9. 「必ず」「絶対」「誰でも」といった言い切りが、原則メモに混ざっていないか
  10. 第三者の個人情報が、どの層にも書き込まれていないか
